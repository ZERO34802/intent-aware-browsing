# Intent-Aware Browsing Extension

An AI-powered browser extension that helps users stay focused and aligned with their browsing intentions.

## 🎯 What It Does

The extension helps you maintain productivity by:
1. **Capturing Intent**: Prompts you to define your purpose when visiting websites (YouTube, Reddit, etc.)
2. **Smart Monitoring**: Periodically analyzes your activity using screenshots and LLM analysis
3. **Real-time Feedback**: 
   - ✅ Positive reinforcement when you're staying on track
   - ⚠️ Gentle warnings when you're getting distracted

## 🏗️ Architecture

- **Extension** (Manifest V3): Chrome extension with content scripts and service workers
- **Backend** (Spring Boot): Java-based API handling LLM integration and analytics
- **LLM Integration**: Gemini/OpenAI for intelligent intent-alignment analysis

## 🚀 Getting Started

### Prerequisites
- Node.js (for extension development)
- Java 17+ and Maven (for backend)
- Chrome browser
